## Findings fixed

The CLI's expected-error list omitted two classes of failures:

- HTTP protocol errors could escape as tracebacks. Synthetic `IncompleteRead`
  and `BadStatusLine` cases reproduced two failing regressions before correction.
  The CLI now handles `http.client.HTTPException` and returns its documented
  concise diagnostic and exit code 2. Regression checks verify that no partial
  destination or staging directory is published.
- A valid JSON integer too large for floating-point scale validation raised
  `OverflowError` before any request. A third regression reproduced it with
  `voxel_size_um: 10**400` encoded as an integer. The CLI now handles that error,
  exits 2 and leaves inputs/output untouched without making a request.

Publication already unwound on these exceptions; the correction makes their
command-line outcome consistent. The source-pin checks, palette mapping and
accepted-data numerical path retain their existing behavior. No other blocking
code finding remains.
